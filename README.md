# ModelForge Studio

### Build. Train. Test. Understand.

ModelForge Studio is an interactive machine learning platform designed to make model training and experimentation accessible through a unified interface.

Users can bring their own datasets, prepare data, configure machine learning models, train them, evaluate performance, explore model behaviour and manage trained models — all within one platform.

### First Working Prototype: Weather Prediction Model

ModelForge Studio currently includes a pre-trained Weather Prediction model built using a Decision Tree algorithm.

This prototype demonstrates the platform's model exploration, prediction, analytics and model management capabilities.

### Platform Capabilities

* Upload and explore custom datasets.
* Prepare and preprocess data.
* Train machine learning models.
* Evaluate model performance.
* Visualize decision trees.
* Generate predictions.
* Import and export supported models.
* Explore model analytics and performance.

**Project Status:** Early Prototype — Under Active Development.
